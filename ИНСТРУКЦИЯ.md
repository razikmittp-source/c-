# Утилита автокликов — установка и запуск на macOS

## 1. Распаковать программу

Присланный файл `ClickerUtility-macos.zip` дважды кликнуть, чтобы распаковать. Появится `ClickerUtility.app`.

Можно перенести `ClickerUtility.app` в любое удобное место, например в Программы.

## 2. Первый запуск (обход предупреждения Gatekeeper)

Программа не подписана сертификатом Apple (это платно и не входит в задачу), поэтому при обычном двойном клике macOS покажет предупреждение и не даст открыть.

Нужно:
1. Правой кнопкой мыши (или Control+клик) по `ClickerUtility.app` → **Открыть**.
2. В появившемся окне ещё раз нажать **Открыть**.

Это нужно сделать только один раз — дальше приложение будет запускаться обычным двойным кликом.

## 3. Выдать доступ Accessibility (обязательно для кликов)

Без этого разрешения программа не сможет кликать мышью — система блокирует автоматические клики от непроверенных приложений.

1. Открыть  **Настройки** (System Settings).
2. Перейти в **Конфиденциальность и безопасность** (Privacy & Security).
3. Открыть **Универсальный доступ** (Accessibility).
4. Найти в списке `ClickerUtility`, включить переключатель напротив.
5. Если программа уже была запущена — закрыть её (Cmd+Q) и запустить заново после выдачи разрешения.

Если приложения `ClickerUtility` нет в списке — нажать `+` внизу списка и вручную выбрать `ClickerUtility.app` из Программ.

## 4. Настройка координат

В открывшемся окне программы:

- **Партия 1 / Партия 2** — задают область (два угла), внутри которой каждый раз случайно выбирается точка для перетягивания (зажать → потянуть → отпустить), количество повторов и направление (вправо/влево).
- **Партия 3** — точка простых кликов, которая выполняется между перетягиваниями партий 1 и 2.
- Кнопка **Пипетка** — нажать, затем кликнуть в нужном месте экрана: координаты подставятся автоматически.
- **Задержка между действиями** — диапазон случайной паузы в секундах между каждым отдельным кликом/перетягиванием.
- **Файл конфигурации** — путь, куда сохраняются настройки. Кнопка **Сохранить настройки** запоминает всё введённое, **Загрузить настройки** — подтягивает сохранённое обратно.

## 5. Запуск и остановка

- Кнопка **▶ Старт** — запускает бесконечный цикл (партия 1 → партия 3 между повторами → партия 2 → партия 3 между повторами → и заново).
- Кнопка **■ Стоп** — останавливает цикл.
- Горячая клавиша **⌘⌥⎋** (Cmd+Option+Esc) — останавливает программу мгновенно, даже если окно не в фокусе.

## 6. Распознавание полосок (индикатор фото)

В **Партии 3** есть опция **«Определять число кликов по индикатору фото»**:

- Если галочка включена — программа перед кликами делает скриншот указанной области (узкая полоска над фото профиля) и считает светлые сегменты.
- **Правило:**
  - 0–1 полоска = 0 кликов (не кликать вообще)
  - 2 полоски = 1 клик
  - 3 и более полосок = 3 клика

**Как настроить:**
1. Включить галочку «Определять число кликов по индикатору фото».
2. Нажать кнопку **«Пипетка»** рядом с «Угол индикатора А» → кликнуть в левый верхний угол области с полосками на экране.
3. Нажать **«Пипетка»** рядом с «Угол индикатора Б» → кликнуть в правый нижний угол области.
4. Нажать кнопку **«Проверить сейчас»** — программа покажет, сколько полосок она видит и сколько кликов сделает.
5. Если цифры не совпадают с тем, что видно глазами — подкорректировать область (повторить шаги 2–4).

**Важно:** Для работы распознавания полосок требуется разрешение macOS **«Запись экрана»** в дополнение к «Универсальному доступу»:
- Настройки → Конфиденциальность и безопасность → Запись экрана → включить для ClickerUtility.

## 7. Что прислать в ответ

Пожалуйста, после того как всё заработает:

1. Скриншот или короткая запись экрана (10-20 секунд) — как программа выполняет клики.
2. Подтверждение, что шаг с Accessibility прошёл без проблем.
3. Если используете распознавание полосок — скриншот окна «Проверка индикатора» с 0 полосками и с 2–3 полосками.

Этого достаточно, чтобы закрыть заказ.
